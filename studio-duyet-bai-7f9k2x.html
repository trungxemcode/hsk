Cổng ChatGPT Plus — Tự động lên bài SEO mỗi giờ

Kết nối ChatGPT Web Plus (Custom MCP Server + Scheduled Tasks) trực tiếp vào hàng đợi Chờ duyệt trên Cloudflare R2. Cổng này chỉ cho nộp bài nháp & xem góp ý — tuyệt đối không có quyền tự duyệt hay push lên GitHub.

Đang tải… Giờ qua: — Tổng bài ChatGPT: 0 Chưa có lượt nộp
Đang tải…
  1. Trên ChatGPT Web Plus, mở chatgpt.com/plugins (hoặc Settings → Apps → Developer mode) → Add custom MCP server → dán URL MCP ở mục 1 → chọn No authentication → Create.
  2. Mở mục Scheduled (Lịch hẹn giờ) trong ChatGPT Plus, chọn chạy lặp lại mỗi giờ, gắn plugin vừa tạo (@HSK SEO Editorial) và dán Prompt hẹn giờ ở mục 4.
  3. Mỗi giờ bài mới sẽ tự hiện trong tab Chờ duyệt của trang này kèm nhãn ChatGPT và điểm Hội đồng AI — chỉ khi bạn bấm ✓ Duyệt & Tự động xuất bản bài mới được push lên GitHub.
